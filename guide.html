The idea

Four agents, a simulated world, a judge, and a loop

Learning happens when you explore diverse strategies in parallel, measure what works, share the wins, and focus on weak spots. A frozen model does none of that. Gandalf wires all four into one loop — and because "the policy" is a growing playbook of lessons injected into the agents' prompts, it learns with zero fine-tuning.

The Swarm policy

Four agents that disagree. Each explores a different strategy — safe, bold, sentimental, novelty. Winners are distilled into a shared playbook each round.

The World data factory

Simulated recipients. A public profile the agents see, and a private hidden_truth answer key they don't. It reacts honestly to every gift.

The Signal reward + curriculum

A judge and a coach. The judge scores thoughtfulness (not "did they buy it"); the coach targets the weakest category next round.

The Rig orchestration

The loop + storage + proof. Runs every episode, persists it, renders the charts that prove learning happened.

The Playbook the "policy"

We don't fine-tune. Learning is this list of lessons growing — distilled from the best episodes, retrieved by relevance, injected into every agent's prompt next round. A better playbook is a smarter swarm.

The loop

One round, repeated until it learns

The same loop runs for a lone agent (the baseline) and for the swarm with distillation. Running both into one store, then plotting both curves, is the ablation.

The proof

We don't assert that it learns — we show it. The third chart is the one we're proudest of: it's the instrument that catches the model gaming its own judge.

Beyond gifts

One engine, many domains

Gifts are just the first domain. The loop is domain-neutral — swap the scenarios, the proposal, and the judge's rubric, and the same engine learns a new task.

Real Claude, routed through a shared gateway (budget-capped, PII-screened). Deployed on Azure Container Apps — trigger a run from the dashboard and watch the curve build live. Storage, retrieval, and the judge are pluggable; the never-cut trio (loop · ablation · validation) is guarded above everything else.
